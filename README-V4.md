# Mariam Art — Astro V4

Локальная версия сайта, созданная на основе проекта Mariam-Art-V3.0 и согласованного дизайна V2. Предыдущий проект не изменён.

## Запуск

Требуется Node.js версии, совместимой с Astro 7, и npm.

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

Откройте адрес, показанный в терминале (обычно http://127.0.0.1:4321). Производственная сборка: `npm run build`; предпросмотр сборки: `npm run preview`.

Работы и переводы находятся в `src/data`, контакты, ссылки и настройки формы — в `site.config.json`. Шрифты Noto и их лицензии — в `public/fonts`. Контактная форма и подписка используют существующую конфигурацию Web3Forms. При проверке формы не выполнялась настоящая отправка: необходимо проверить доставку на настроенный адрес перед публикацией.

Сайт содержит армянский, русский и английский языки, две темы, галерею, поиск и адаптивные страницы. На первом экране и в галерее используются фотографии работ из прежнего проекта. Реальный портрет автора пока не добавлен.
