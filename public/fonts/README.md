Шрифты для новой версии Mariam Art: Noto Serif и Noto Sans, включая отдельные армянские семейства. Файлы и лицензии OFL получены из официального репозитория google/fonts. Новые русскоязычные экраны переводятся на Noto Serif и Noto Sans; старые варианты в документе сохранены с Georgia/Arial. Армянские начертания подготовлены для будущей реализации и требуют проверки после перевода интерфейса.
